# FormSubmit

The form's submit button, which knows when a submission is in flight.

```tsx
<FormSubmit>Create account</FormSubmit>
```

It reads `submitting` from the form level of the adapter, shows the pending state and blocks a second
submit — the small thing every form needs and every form forgets, which is why it belongs here
rather than in each call site.

## Props

Everything `Button` takes, except `type`, which is fixed to `submit`.

## Accessibility

- **Pending, not disabled.** It uses `Button`'s `isLoading`, which keeps the control focusable and
  announces the state through a live region. A native `disabled` would drop focus mid-interaction and
  leave a screen-reader user with nothing under the cursor, right after the action they just took.
- The pending state comes from the **form**, not from the click, so it stays true for as long as the
  submission actually takes — including a redirect or a server round trip the button never sees.
