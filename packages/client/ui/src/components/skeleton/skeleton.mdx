# Skeleton

A grey stand-in for content that has not arrived, so a loading page keeps its
shape instead of collapsing and jumping when the data lands. It is decorative
by construction — hidden from assistive tech, with the loading state left to
the region it sits in.

## Usage

### Shapes

Three, and each one carries a decision you would otherwise re-derive: `text`
takes its height from the type around it, `block` has a panel's corners, and
`circle` stays round when you resize it.

<Canvas of={SkeletonStories.Gallery} />

### A paragraph

There is no `lines` prop. A paragraph is a stack of lines and its rhythm — the
gap, the short last line — belongs to the layout around it, which is also what
makes the placeholder match the real text. `text` reads the font size on its
own, so the heading below is heading-sized with nothing passed.

<Canvas of={SkeletonStories.Paragraph} />

### Swapping, not wrapping

`Skeleton` takes no children and has no `loading` prop: it is a box, not a
wrapper. Branch at the call site, where the loading actually happens.

```tsx
{
  isPending ? (
    <Skeleton shape="circle" />
  ) : (
    <Avatar name={user.name} src={user.avatar} />
  );
}
```

### Size

`text` and `block` span the inline axis; you give `block` a height and
`circle` a width. Use `style` — consumers import precompiled CSS and are not
required to run Tailwind, so a utility class is not a portable way to size one.

## Accessibility

- **Every skeleton is `aria-hidden`, always.** Three grey boxes announced one
  by one tell a screen-reader user nothing, and the attribute is written after
  the props spread so it cannot be turned off — this is the component's
  contract, not a default.
- **The region owns the state, not the placeholder.** Put `aria-busy="true"`
  on the container that is waiting and drop it when the content lands.

  <Canvas of={SkeletonStories.LoadingRegion} />

- **When the wait itself needs a name, use [`Progress`](?path=/docs/components-feedback-progress--docs)
  with no `value`** — an indeterminate bar with a label. It is the component
  that announces; two components announcing one wait is worse than one.
- **Reduced motion stops the pulse entirely.** Unlike `Progress`, nothing is
  lost by stopping it: a grey slab where a sentence belongs reads as "not yet"
  whether it breathes or not, which makes the animation decoration — and
  decoration is what the preference asks to be spared.
- **Windows High Contrast** repaints the fill as `GrayText`, the system's own
  colour for content that is not active yet. Without that block the box would
  flatten to `Canvas` and the loading page would be blank.
